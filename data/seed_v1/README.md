# TODDO seed set v1

Generated by `toddo generate`. Files: `records.jsonl` (accepted samples),
`review_queue.jsonl` (needs_review/rejected), `manifest.json` (counts + provenance).

## Provenance & status

This checked-in build is **offline**: template operators (real gold labels) +
no LLM paraphrase + `HeuristicJudge` (deterministic gate). Real, schema-valid
(coherent, perturbed) pairs with real gold coherence labels, dimensions, and
5-pass provenance — but the surface wording is the plain template fallback and
the judge is heuristic, not an LLM.

For the research-grade curated set:
```bash
# 1. configs/models.yaml with a real generator + judge (see models.example.yaml)
PYTHONPATH=src python -m toddo.cli generate --live
# 2. human-review review_queue.jsonl before promoting to records.jsonl
```
`manifest.json` records which generator/judge actually ran.
